# POTIK.LIVE — прототип новостного агрегатора

Собрано по ТЗ: сбор новостей из RSS украинских/зарубежных порталов → дедупликация
(fuzzy matching по заголовку) → рерайт через LLM (украинский язык, с учётом
правил использования каждого источника) с guard-слоем → автопубликация без
ручной модерации → публичная лента с SEO → заглушки под рекламу → админка.

## Стек

- **Next.js 14** (App Router, ISR) — фронтенд + API-роуты
- **Prisma + PostgreSQL** (Neon) — БД
- **rss-parser** — чтение RSS-фидов
- **string-similarity** — fuzzy-дедупликация заголовков
- **Claude API** (`claude-sonnet-4-6`) — рерайт текста, промпт на украинском,
  выход всегда на украинском независимо от языка источника

## Быстрый старт

```bash
npm install
cp .env.example .env
# впишите в .env: DATABASE_URL и DIRECT_DATABASE_URL (строки из Neon —
# DIRECT_DATABASE_URL обязателен для миграций, у Neon это адрес без -pooler),
# ANTHROPIC_API_KEY, ADMIN_PASSWORD, CRON_SECRET, SESSION_SECRET

npx prisma migrate dev --name init   # создаст таблицы в Postgres по схеме
npm run seed                          # добавит 3 источника (см. ниже)

npm run pipeline                      # разовый прогон: сбор → дедуп → рерайт → публикация
npm run dev                           # запуск сайта на localhost:3000
```

Админка: `/admin/sources` (логин из `.env`: `ADMIN_USERNAME` / `ADMIN_PASSWORD`).

## Структура

```
prisma/schema.prisma        — схема БД (Source, RawItem, ArticleGroup, Article, RewriteLog, AdminUser)

src/lib/rss.ts                — Модуль 1: сборщик источников
src/lib/dedup.ts              — Модуль 3: дедупликация (fuzzy matching, порог 0.72)
src/lib/rewrite.ts            — Модуль 2: рерайт через LLM + guard-слой + автопубликация
                                  (per-source пороги длины и подсказки по длине текста — SOURCE_MIN_LEN,
                                  SOURCE_LENGTH_HINTS)
src/lib/pipeline.ts           — оркестрация полного цикла
src/app/api/cron/route.ts     — эндпоинт для внешнего планировщика
src/app/admin/*                — админка: источники / лента публикаций / лог ошибок / логин
src/app/layout.tsx             — общая шапка (POTIK.LIVE, категории), шрифты
src/app/page.tsx               — главная лента (hero + миниатюры + плотный список + сайдбар "Популярне")
src/app/article/[slug]/        — страница статьи (хлебная крошка, фото, JSON-LD NewsArticle, "Статті по темі")
src/app/category/[slug]/       — раздел "Україна в пресі"
src/app/sitemap.ts             — динамический sitemap.xml
src/components/AdSlot.tsx      — заглушка рекламного блока (фиксированная высота — защита от CLS)
.github/workflows/cron.yml     — планировщик (см. "Деплой" ниже, не Vercel Cron)
```

## Источники (seed)

Активны: **ZN.UA**, **Euromaidan Press**, **Радіо Свобода** (укр. служба RFE/RL).
Все трое явно разрешают использование с атрибуцией — проверено напрямую по
правилам каждого сайта, обоснование по каждому источнику — в комментариях
`prisma/seed.ts`.

Изначально рассматривались ещё 5 украинских порталов (УНІАН, NV.ua,
Українська правда, Фокус, Факти ICTV) и Interfax-Ukraine — все исключены:
их правила прямо запрещают коммерческий рерайт без письменного разрешения.

3 источника — мало для полноценного продукта. Варианты расширения и уже
отклонённые источники с причинами — см. комментарий в конце `prisma/seed.ts`.

## Known-issues и откалиброванные решения

- **Guard-пороги длины — per-source, не общие.** `MIN_LEN = 300` — дефолт,
  но источники сильно отличаются по объёму RSS-контента: Euromaidan Press
  (150), ZN.UA (200), Радіо Свобода (200) — пороги ниже, потому что их
  короткие новости (одно-два предложения в фиде) после честного пересказа
  без выдумывания фактов физически не дотягивают до 300 знаков. Это
  откалибровано на реальных прогонах, не угадано заранее.
- **Промпт жёстко требует украинский язык** вне зависимости от языка
  источника (часть фидов отдаёт русскоязычные материалы) — сайт
  одноязычный, смешение языков в ленте было реальной проблемой на старте.
- **REFUSAL_PATTERNS учитывают кириллицу аккуратно** — в JS `\b` не видит
  кириллические буквы, обычная граница слова даёт ложные срабатывания
  (например, "як ші" ложно матчится внутри "як шістнадцять"). Используется
  `(?!\p{L})` с флагом `u` вместо `\b`.
- **Модерация отсутствует.** Публикация полностью автоматическая, брак
  отсекается только программным guard-слоем. Постфактум-аудит — в `/admin/failed`.
- **Только RSS summary**, без скрейпинга полной страницы источника.
- **Один админ-аккаунт** без ролей — логин/пароль в `.env`, без RBAC.
- Зависимости проверены на уязвимости (`npm audit`); закрыты все, кроме одной
  критической в `next@14.2.x` (image optimizer DoS через `remotePatterns`) —
  проект не использует `next/image` с `remotePatterns`, не эксплуатируется
  в текущем виде.

## Деплой

**База** — Postgres (Neon, бесплатный тариф). Миграции идут через
`DIRECT_DATABASE_URL` (прямое подключение, без `-pooler` в адресе хоста) —
через пулер миграции Prisma могут подвисать.

**Планировщик — НЕ Vercel Cron.** На Vercel Hobby (бесплатный тариф) cron-задания
ограничены одним запуском в сутки — расписание `*/30 * * * *` завалит деплой.
Вместо этого используется `.github/workflows/cron.yml`: бесплатный планировщик
GitHub Actions дёргает `/api/cron` каждые 30 минут, минуя это ограничение.
Нужно прописать секреты `CRON_SECRET` и `SITE_URL` в настройках репозитория
(Settings → Secrets and variables → Actions). Если перейти на Vercel Pro —
можно вернуться к `vercel.json`-крону, тогда GitHub Actions-воркфлоу не нужен.
